# StreamWave IPTV — Etapa 1

Projeto Android inicial em Kotlin e Jetpack Compose.

## Requisitos
- Android Studio compatível com Android Gradle Plugin 8.13.0
- JDK 17
- Android SDK 36

## Abrir
1. Extrair o ZIP.
2. No Android Studio, escolher **Open** e selecionar a pasta `StreamWave-IPTV-Etapa1`.
3. Aceitar a sincronização Gradle.
4. Executar em emulador ou dispositivo Android (API 26 ou superior).

## Estado real desta etapa
- Estrutura Android e configuração Gradle criadas.
- Ecrã inicial em Compose criado.
- Tema escuro e navegação visual inicial criados.
- Importação IPTV, navegação funcional, player, base de dados e restantes funções ainda não implementados.
- **Não foi possível executar uma compilação Android neste ambiente**; a etapa só fica validada depois de sincronizar e compilar no Android Studio.
